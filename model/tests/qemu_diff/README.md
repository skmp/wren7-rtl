# qemu_diff batches

Differential instruction-semantics tests, generated by `tools/qemu_diff.cpp --gen` (seeds 1-4, 1000 cases each).
The reference is qemu-arm `-cpu sa1100` (ARMv4); only behaviour ARMv3 and ARMv4 define identically is generated
(see the header of `tools/qemu_diff.cpp` for the classes and exclusions).

Per batch `s<seed>/`:

| file | what |
|---|---|
| `prog.s` | the test program (assemble with `arm-eabi-as -mcpu=arm7`, link `-Ttext=0x10000 -z max-page-size=0x1000`) |
| `cases.tsv` | one line per case: index, class, instruction word, CPSR compare mask, scratch region (-1 = none) |
| `expected.bin` | qemu's output: `out_tab` (64 bytes per case: r0-r12, r14, CPSR, pad) then `scratch` (128 bytes per region) |

Check the model against all batches (no qemu needed): `../build/model/qemu_diff` from `wren7-rtl/model`.

## Running a batch on the console (not built yet)

`prog.s` is written to run unchanged on the AICA ARM:

- Link as above; the image goes to wave RAM at ARM address 0x10000 (SH4 side 0x00810000).  `in_tab`, `out_tab`,
  `scratch` come from the ELF symbol table.
- Vectors the console runner must supply at 0x00-0x1F: reset -> `b 0x10000`; SWI (0x08) -> a stub that sets a done
  flag and spins.  The program ends at its first `SWI 0` (qemu-user treats the three SWIs as write/write/exit).
- It runs in the mode reset leaves (SVC, I = F = 1); r13 is its table pointer, nothing else is assumed.
- Compare `out_tab` (CPSR masked with the case's mask: qemu runs in user mode, so only flags count) and `scratch`
  with `expected.bin`, exactly as `check_batch()` in `tools/qemu_diff.cpp` does.
